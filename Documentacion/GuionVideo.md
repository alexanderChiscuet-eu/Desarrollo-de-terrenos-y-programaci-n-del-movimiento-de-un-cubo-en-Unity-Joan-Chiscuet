# Guion sencillo para el video (3 a 5 minutos)

- 0:00 a 0:30: presenta la escena y su objetivo: aprender a usar terrenos, cubos y materiales en Unity.
- 0:30 a 1:15: muestra el terreno verde y sus colinas. Explica que se preparo una zona plana para la ciudad.
- 1:15 a 2:00: muestra los diez edificios de colores, las calles negras, las aceras, los arboles y los dos coches decorativos.
- 2:00 a 3:00: pulsa Play y recorre la escena con WASD o flechas; muestra la camara de seguimiento y el reinicio con R.
- 3:00 a 3:40: muestra MovimientoCubo.cs y el README. Explica brevemente como se mueve el cubo.
- 3:40 a 4:00: comenta lo aprendido y cierra la demostracion.

Graba la ventana de Unity y narra con tus palabras. Publica el video en YouTube como no listado o en la plataforma permitida por el docente. Entrega el enlace del video y del repositorio GitHub.

## Publicar el proyecto en GitHub
1. Extrae el ZIP y abre la carpeta que contiene Assets, Packages y ProjectSettings.
2. En GitHub Desktop, usa File > Add local repository. Si aun no tiene Git, usa la opcion para crear el repositorio en esa carpeta.
3. Haz un commit y pulsa Publish repository.
4. Comprueba que esten Assets, Packages, ProjectSettings, Documentacion y README.md; conserva todos los .meta.
5. Entrega el enlace real del repositorio y del video en la plataforma del curso.
